This website is available in four different formats, across three protocols.  They all have (roughly) the same content, just different formating, either for accessibility or because of the limitations of the transfer protocol.  The following versions are available:
# BIG WEB VERSIONS
The **BIG WEB** is the internet through a standard web browser.  The vast majority of you are using one of the two versions available on the **BIG WEB** (if all this talk about protocols is gibberish to you, you're using one of these).  Personally I prefer the simplicity of the lite version for blog reading, but the main version has some fun JS components/animations, it's a better showcase of my programming.
### HTTP(S)
* [https://fatcullen.com](https://fatcullen.com)  
Main version, built with NextJS
* [https://lite.fatcullen.com](https://lite.fatcullen.com)  
Lite version, at the `lite.` subdomain  
Basic HTML + CSS, without all the fancy React components  
Optimized for viewing with JS off, or through a text based web browser  

# SMALL WEB VERSIONS
The *small web* uses protocols other than HTTP(S).  You'll need a specialized browser to access these pages (I recommend [Lagrange](https://github.com/skyjake/lagrange)).  These protocols only have a few hundred or a couple thousand servers total, which is *tiny*, and the transfer formats have heavy limitations.  In return though, you get **no** ads, **no** pop-ups, **no** tracking, and a guarantee everything is made by real passionate people.  I host on these protocols:
1. Because it was a fun project to get this website to build across all these formats.
2. Because I love using the *small web* and wanted to add to it!  Sifting through the current sea of slop articles to find good content is getting tiring, and browsing these protocols is a way to avoid that.  I encourage you to try these formats out.  

### Gemini 
[Project Gemini](https://geminiprotocol.net/) is a newer protocol, created in 2019, with the goal of being a more modern *small web* format.  Websites are written in the *Gemtext* format, sort of like an improved *Markdown*.  This lets them look better than Gopher sites, while still keeping that *small web* simplicity.  You can find the site hosted in Geminispace at its standard URL:
* [gemini://fatcullen.com](gemini://fatcullen.com)

### Gopher
[The Gopher protocol](https://commons.lib.jmu.edu/cgi/viewcontent.cgi?article=1196&context=selectedworks) was an early alternative to HTTP, which fell into obscurity (think [Betamax vs. VHS](https://en.wikipedia.org/w/index.php?title=Videotape_format_war&oldid=1343706489)).  It's effectivley the predecessor to the modern World Wide Web.  Pages have a very basic menu-style layout, just plain text and links.  You can find the site hosted in Gopherspace at its standard URL:
* [gopher://fatcullen.com](gopher://fatcullen.com)
